# Airline Scorecard: Which airline is actually on time?

Stakeholder: Corporate travel desk choosing a default airline for busy routes.
Decision: Which airline to book by default, and when to switch.

Questions this project answers:
1. Which airline has the best on-time performance over 12+ months, and is it consistent?
2. Does that airline also have low cancellations and complaints?
3. Does the ranking change in monsoon or fog season?
